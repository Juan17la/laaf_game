How the player moves

From the title screen to the fog and back. Every screen in LAAF is at most three steps from play, Esc always goes back one level, and nothing irreversible happens without a page that says so.

Transitions

Every route, with the input that takes it on each device. The mouse mirrors the keys everywhere: pointing selects, a left click acts like Enter, a right click goes back like Esc, and the help bar's keycaps are clickable.

Focus inside the dossier

The main menu has two focus levels, so the same keys can move between pages or within one.

Tabs focus

W/S (or up/down) change the open tab, with a leaf turn. The page's rust bar is armed: Enter fires it directly (RESUME, QUIT TO DESKTOP), or enters the page (NEW, LOAD, OPTIONS, DEV).

Enter / A / click on page →
← Esc / B / right click
Page focus

W/S move the selection inside the page (difficulty rows, saves, options, steps). A/D adjust a setting. Enter acts. Esc returns to the tabs; Esc again returns to the title screen.

Navigation rules

Esc is always "back one level"

Page → tabs → title on the main menu. Options or Leave → pause page → game in the pause menu. Inventory, wheel and minigames close straight to the game.

Irreversible actions get their own page

Quitting, leaving a run and resetting settings each ask first, and say what happens (saves kept, unsaved progress lost).

Resuming happens on release

Whatever lets the game go on fires when the button is released, so the click that closes a menu never fires the gun.

Menus only open when they can help

The inventory and wheel are blocked during cinematics, minigames and death. Save game is greyed out with a reason in dev runs and when Alex isn't in control.

Three steps from play, at most

Title → dossier → RESUME is two key presses for a returning player: any key, then Enter. Every in-game menu is one key away from the game.

The help bar always tells the truth

It shows only the keys that work on this page, in this focus, for the device used last (keyboard names or pad buttons).
